# Alquilaap

Marketplace para alquilar objetos entre particulares y tiendas (bicis, herramientas, camping, foto, fiestas...).

- **Publicar y alquilar es gratis.** Alquilaap no cobra comisión ni retiene pagos: el alquiler y la fianza se pagan en mano entre usuarios.
- **Ingresos:** packs de visibilidad (Básico, Pro, Premium) y la suscripción **Alquilaap Pro** para tiendas.
- **Confianza:** identidad verificada obligatoria, doble confirmación («alquilado» y «finalizado» por ambas partes), incidencias, seguro opcional y reseñas.
